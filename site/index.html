pepe

An HTTP load generator with a live dashboard, built to cost less than the server it tests.

curl -LsSf https://pepe.mhaimdat.com/install.sh | sh

Installs to ~/.local/bin, puts it on your PATH, and sets up tab completion and man pepe for your shell. Updates later with pepe self-update.

powershell -ExecutionPolicy Bypass -c "irm https://pepe.mhaimdat.com/install.ps1 | iex"

Installs to ~\.local\bin, puts it on your PATH, and sets up tab completion for PowerShell. Updates later with pepe self-update.

brew install omarmhaimdat/pepe/pepe

macOS and Linux. Completions and the man page go where Homebrew activates them.

nix profile install github:omarmhaimdat/pepe

Or try it without installing: nix run github:omarmhaimdat/pepe -- https://example.com

cargo install --locked --git https://github.com/omarmhaimdat/pepe

Then pepe completions --install for tab completion and the man page. Prebuilt, signed binaries for every platform are on the releases page.

then

pepe https://example.com

What you get

  • A live dashboard with a latency heatmap, percentiles, throughput, status codes, failure causes and a request log you can open any request from. Pause, resume and change concurrency while it runs.
  • A verdict in plain words when the run ends: Healthy, Degraded or Failing, and why.
  • Any curl command as input, straight from a browser's "Copy as cURL".
  • A setup screen when you run pepe on its own, ramp mode to find where a target stops keeping up, and API mode for the endpoints of an OpenAPI spec.
  • Light: one thread sends about 100k requests a second at 2.5× less CPU than comparable tools, and pepe says when it, not the target, is the limit.
