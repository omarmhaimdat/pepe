Load test it. Then read what happened.

pepe is an HTTP load testing tool with a live terminal dashboard and a verdict in plain words. One small binary, light enough that the server is what you measure.

curl -LsSf https://pepe.mhaimdat.com/install.sh | sh

Installs to ~/.local/bin with tab completion and man pepe. Later: pepe self-update.

powershell -ExecutionPolicy Bypass -c "irm https://pepe.mhaimdat.com/install.ps1 | iex"

Installs to ~\.local\bin with tab completion for PowerShell. Later: pepe self-update.

brew install omarmhaimdat/pepe/pepe

macOS and Linux. Completions and the man page go where Homebrew activates them.

nix run github:omarmhaimdat/pepe -- https://example.com

Or keep it: nix profile install github:omarmhaimdat/pepe

docker run --rm -it ghcr.io/omarmhaimdat/pepe https://example.com

A few megabytes, for linux/amd64 and linux/arm64.

cargo install --locked --git https://github.com/omarmhaimdat/pepe

Signed binaries for every platform are on the releases page.

A verdict, not a spreadsheet

It says what the numbers mean.

When a run ends pepe leaves a verdict in your shell: one word, and the findings behind it. Failures are grouped by cause with the first response body, so "503 from the upstream" is there without opening a log.

What it does

One endpoint, a whole API, or last night's traffic.

Every mode has the same dashboard, the same verdict, and a --json report for scripts.

Run

Send load at a URL and watch latency, throughput and errors as they happen. Pause, resume and change concurrency while it runs.

pepe -z 30s -c 50 https://example.com

Ramp

Raise the load step by step to find where the target stops keeping up, with a capacity estimate at the end.

pepe ramp URL --to 200 --until 'p99 > 500ms'

Any curl command

Paste "Copy as cURL" from a browser, Postman or Insomnia. It is sent exactly as curl would send it.

pepe --curl -- curl -X POST URL -d '{"a":1}'

OpenAPI

Load test the endpoints of an OpenAPI 3 or Swagger 2 spec, picked by tag, with parameters and credentials set on screen.

pepe api openapi.yaml --tag Billing

Flows

A sequence of requests where each step feeds the next: log in, take the token, add to cart, check out.

pepe flow checkout.toml -c 20 -z 1m

Replay

Send the URLs of an access log in their real proportions, so staging sees the mix production does.

pepe replay access.log --base-url https://staging

Open model

A fixed arrival rate instead of fixed concurrency, and pepe says when the concurrency you gave it can't carry it.

pepe --rate 500 -c 100 -z 2m URL

Soak

Hours-long runs that write their report every minute, so a crash at hour six doesn't lose the data.

pepe -z 8h --snapshot soak.json URL

Setup screen

Run it with no arguments and fill in a form. The equivalent command is shown as you go, and saved as pepe.toml if you like.

pepe

pepe logs

And what the server saw.

Point pepe at nginx's access and error logs and it shows the server as it is right now: live, on the host, with nothing to install but pepe.

pepe logs /var/log/nginx/access.log

Docker too: docker compose logs -f nginx | pepe logs

  • Requests a second now, against a usual minute, hour and day.
  • A verdict: Steady, Busy, Degraded or Failing, with the path that fails and what the error log says of it.
  • Top paths, clients, status codes and the error log grouped by cause.
  • Any size of log: read by every core at gigabytes a second, in memory that doesn't grow with the file.

Light

Built to cost less than the server it tests.

A load generator that is busy can't tell you the server is. pepe is measured against wrk, oha and vegeta on every release, and tells you when it, not the target, is the limit.

In a pipeline

Fail the build when p99 slips.

The repository is a GitHub Action: it installs a pinned release, runs the test, puts the numbers in the job summary, and fails the job on a condition over the report.

  • JSON with the same percentiles the dashboard shows.
  • Docker image at ghcr.io/omarmhaimdat/pepe.
  • A config file: pepe.toml in a project, so pepe there runs the agreed test.
- uses: omarmhaimdat/pepe@master
  with:
    url: https://staging.example.com/api/health
    args: -z 30s -c 20
    fail-if: ".summary.latency.p99_ms > 300
      or .summary.failed_requests > 0"

# or anywhere else
pepe --json -z 30s -c 20 URL > report.json
