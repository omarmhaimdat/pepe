For agents

Your agent runs it.
The guardrails hold.

Every mode is an MCP tool. Caps on host, count, rate and connections are checked before anything is sent, and a refusal is exit code 2 with the reason.

# next to the code: holds for every run here
allow-host      = [".staging.example.com", "localhost"]
max-requests    = 10000
max-rate        = 500
max-concurrency = 64
{
  "schema_version": 1,
  "summary": {
    "requests_per_second": 3920.4,
    "latency": { "median_ms": 41.2, "p99_ms": 188.0 }
  },
  "spans": { "operations": [ { "name": "db.query orders", "share_percent": 38.5 } ] }
}

--allow-hostOnly the hosts you name, every step and every row.
--max-rateAn open loop at a rate you bound, never as fast as it goes.
--dry-runWhat would be sent, where and how much, secrets masked.
--fail-if 'p99 > 500ms'Exit code 4 when a line is crossed.
