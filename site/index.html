A load generator with a live terminal dashboard and a verdict in plain words. One small binary, light enough that the server is what you measure.

what a run leaves in your shell
what it doescommand
runpepe -z 30s -c 50 https://example.comsend load, watch latency, throughput and errors live; pause, resume, change concurrency
ramppepe ramp URL --to 200 --until 'p99 > 500ms'raise the load step by step to find where the target stops keeping up
curlpepe --curl -- curl -X POST URL -d '{"a":1}'any “Copy as cURL”, sent exactly as curl would send it
apipepe api openapi.yaml --tag Billingevery endpoint of an OpenAPI 3 or Swagger 2 spec, a row each
flowpepe flow checkout.toml -c 20 -z 1ma sequence where each response feeds the next request
replaypepe replay access.log --base-url https://stagingan access log's URLs in their real proportions
ratepepe --rate 500 -c 100 -z 2m URLa fixed arrival rate; pepe says when -c can't carry it
soakpepe -z 8h --snapshot soak.json URLlong runs that write their report every minute
logspepe logs /var/log/nginx/access.lognginx's logs live: requests a second now against a usual minute, hour and day
jsonpepe --json -n 10000 URL > report.jsonno dashboard; the same numbers for scripts and CI
setuppepeno arguments: a form for every option, saved as pepe.toml if you like
