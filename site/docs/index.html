pepe

An HTTP load generator with a live dashboard, built to cost less than the server it tests. Load-test a URL, ping it to see where the time goes, ramp to find the capacity, and read the result as a verdict or a JSON report.

Where to start

  1. Install it.
  2. Run pepe https://your.service/health and read the dashboard; q leaves the verdict in your shell.
  3. Leave pepe ping https://your.service/health open while you deploy, or run pepe ping URL --once to see why it is slow (Ping).
  4. Put the test next to the code as a pepe.toml (config file) and run it in CI with the GitHub Action or --fail-if (Output).

The plan for what comes next is in ROADMAP.md, and what changed in each release in CHANGELOG.md.
